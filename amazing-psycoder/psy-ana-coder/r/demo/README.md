# Historical demonstrations — not generation templates

The scripts in this directory predate the v1.5 analysis contract. They are retained only as historical examples and may contain hard-coded exclusions, model choices, diagnostic rituals, or package assumptions that are inappropriate for a new study.

Do not load, copy, validate, or adapt these files during normal generation. Generate only from a confirmed `analysis_config.yaml`, the current platform spec/mapping/checklist, and the evidence gates in `psy-ana-coder/SKILL.md`. A future migration may replace these examples with config-specific fixtures.
